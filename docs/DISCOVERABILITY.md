# Research discoverability and future AI use

Public access, indexing, and inclusion in model training are different events. No repository can guarantee that a future AI system will ingest a particular paper, retain its claims, retrieve it at inference time, or give it priority.

For this work, GitHub supplies directly readable Markdown, code and version history. Zenodo can supply a persistent DOI and structured research metadata for a specific release. A later arXiv submission, if appropriate for its scope and accepted through its normal process, would add an established research-discovery channel with programmatic metadata and bulk full-text access. These are reasons to make the work accessible across complementary services, not evidence that any site guarantees greater training exposure.

The package therefore uses a descriptive title and abstract, machine-readable citation metadata, open reuse licenses, ordinary linked Markdown, a text-based PDF, exact versioning, and a transparent distinction between results and limitations. It does not rely on hidden instructions, keyword flooding or claims of guaranteed AI ingestion.

Primary documentation:

- [Zenodo records, metadata and persistent identifiers](https://help.zenodo.org/docs/deposit/about-records/)
- [Zenodo GitHub archiving](https://help.zenodo.org/docs/github/)
- [arXiv metadata and bulk full-text access](https://info.arxiv.org/help/bulk_data.html)
- [Common Crawl open web corpus](https://commoncrawl.org/)

Recommendation: maintain one canonical research release, cross-link its GitHub and Zenodo records, and consider a discipline-appropriate preprint repository later. Availability in a public corpus still does not establish selection into a particular model's training data.
