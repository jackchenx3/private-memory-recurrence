# Exact implementation and verification scope

The mathematical kernel is defined directly in kernel.py; no former population simulator or empirical preparation is imported. Only the generic I/O hashing/resource monitor and idempotent transport pattern are reused, with dependency hashes. State index order and all fourteen keys are fixed before production.

Producer rows preserve the literal2×4×4×4×56×4 event tree. The two policy-flip outcomes for each survivor are unrolled into four exact additions at distinct policy-bit toggles. No duplicate slots, unused H fresh bits, source states or outcomes are collapsed. Integer division is applied only where W(W−w) divides the fixed L. Independent row code uses full genotype/cache/policy tuples, a separately written donor rule and explicit flip loops; it imports no producer implementation.

The local preproduction suite checks only the permitted32 rows, not complete production matrices or stationary vectors. It also checks101 constructed two-state residual vectors and a fixed-precision solve for a two-state chain. Synthetic supplied vectors test reward/contrast orientations and outward rounding without solving the study model. Those fixtures do not select rates, precision or hypotheses.

Production writes intent before each kernel and solve, row chunks every32 rows, then completed matrix/vector receipts. It attempts each fixed solve once. Every computed solution is retained before rounding validation. An exception or invalid vector is reported as rejection without clipping; residual criterion failures remain explicit. No fallback solver, precision increase, burn-in, sampled path or automatic new allocation exists.

The certificate uses normalized k/K, exact R and rational r/E. It does not square integer matrices or rely on floating residuals. The two-step minorization argument is recorded in the brief and checked arithmetically in fixtures. Full support and exact symmetry are producer checks; the independent checker recomputes all saved certificates and fourteen outcome records, not another stationary solve. Supervisor review remains separately identified.
